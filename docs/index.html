the gene-expression language

Six mechanisms, one grammar

Operon borrows its control layer from the gene-expression machinery of the cell — mechanism names only, each mapped to a concrete language feature (SPEC.md §16).

⤨ wobble

Wobble tolerance

In translation, loose pairing at the third codon position lets one codon family be read by fewer tRNAs. Operon's parser does the same: misspell a keyword within edit distance and it is repaired, logged as a wobble note, and the program runs.

≡ frames

Overlapping frames

Viruses read one sequence in shifted frames to get two proteins from one genome. One .op file is one sequence: frame proof is the test reading frame that operon test translates, and operon run skips.

⌇ splice

Splice variants

One gene, several mature mRNAs. splice declares alternative bodies for one gene name; --variant, the .cell config, or an @m6a mark picks which variant is active at dispatch time.

✎ edit

RNA editing

Transcripts can be chemically amended after transcription. .rna patches rewrite a target file's source text — hot-fixes applied before parsing, each replacement logged.

⛨ guard

uORF guards

Upstream open reading frames gate the main transcript: if conditions are poor, translation stops early. A guard (cond) else { } clause sits between signature and body and trips softly, returning null with a note — never a crash.

◉ methyl

Methylation layer

Cells silence regions epigenetically without touching the genome. A .cell config file plus @methylate / @acetylate marks and methyl() reads reprogram the same source without editing it.
