01

Variables & values

Mechanism · cytoplasmic pool A cell's cytoplasm is not a registry of constants but a pool in flux: transcripts and proteins have current abundances, and every binding site is either occupied or unbound. Operon mirrors this — let establishes a binding, plain assignment updates it, and there is no "undefined variable" crash: reading an unbound name yields null with a note, the way a probe over an empty site reads zero, not catastrophe. Numbers keep the int/float distinction the runtime needs for exact transcript counts versus continuous rates.

02

If, elif, match

Mechanism · checkpoint control The cell makes commitment decisions at checkpoints: crossing a signaling threshold flips a switch from one chromatin state to another, and the states are discrete — poised, active, repressed — not a continuum. if/elif/else is the threshold cascade. match is the panel of probes: each case is a literal test against the value, an identifier binds the value for the block, and _ is the wildcard. Like a probe array, the first positive reading wins and the rest are not consulted.

03

Loops & collect

Mechanism · polymerization cycles Biosynthesis is iterative machinery: the ribosome translocates one codon at a time in a loop that only terminates at a stop signal, and polymerases repeat a cycle until dissociation. loop is the ribosome — open-ended, exited only by an explicit terminator; while is a polymerase with a defined template length; for walks an existing sequence base by base (lists yield items, strings yield one-character strings, maps yield keys). collect is the condensation reaction itself: one pass over a template, one product list, with an optional if acting as fidelity filtering.

04

Genes & closures

Mechanism · the operon & chromatin context An operon is a cluster of genes transcribed as one unit under shared regulation — which is exactly what a closure is: the function carries its defining regulatory environment with it. A gene defined inside make_counter keeps access to the local n the way a gene in a chromatin loop keeps contact with its enhancers, regardless of where execution later travels. Defaults are constitutive expression levels (used when nothing else is specified), missing arguments degrade to null with a note, and the full language adds guard (cond) else { } — an upstream-ORF clause that can quietly refuse translation before the body ever runs.

05

Strings & interpolation

Mechanism · the mature transcript A messenger RNA is a composed message: coding segments, untranslated arms, chemical amendments. Interpolation is translation in miniature — any expression inside { } is evaluated at runtime and coerced with str(), the way a ribosome renders a codon region into residue in place. Escapes (\n \t \\ \" \{) are the post-transcriptional modifications: they change what the message says, not what was encoded. Methods like .split, .join, and .replace are the editing enzymes that cut and ligate the message after it exists.

06

Lists, maps, methods

Mechanism · metabolite pools & pathway flux A metabolic pathway is a pipeline: each enzyme takes the pool it is given, transforms it, and hands it downstream — .map is that flux, .filter is a membrane that passes only some species, and .reduce condenses a pool into a single summary metabolite. Maps are the cell's ledger: an insertion-ordered record of which factor binds where, with .keys() reading the row headings in the order they were written. Membership (in) is a binding assay — deep equality for lists, substring for strings, key presence for maps. Missing keys read as null with a note: an empty assay well, not an alarm.

07

Stress & rescue

Mechanism · unfolded protein response When misfolded proteins accumulate, the cell does not halt — it runs a containment program: translation narrows, chaperone production rises, and the compartment rides out the insult. Operon's stress { } rescue { } is that program. A runtime failure raises a Stress value — a map of kind and message — with kinds named for the damage: unfolded (type errors), missing (bad index/key), overflow, burned (failed assertions). An unqualified rescue catches everything; a kind filter catches only that lesion class and lets others propagate outward, exactly as a response pathway is specific to one misfold class. With no rescue clause at all, the stress is contained to null plus a note — the run continues.

08

TADs & anchors — modules

Mechanism · topologically associating domains The genome is folded into self-contacting loops bounded by architectural anchors. Inside a loop, enhancers and promoters talk freely; across the boundary, they are electrically silent — insulation prevents an enhancer in one domain from mis-driving a promoter in the next. tad is that loop: names inside are invisible outside and escape only through an anchor export placed within the same domain, the way only loop-boundary elements are exposed to the neighboring loop. anchor import is the declarative statement that a domain expects an external factor to exist — the checker verifies it, and reports a note if the factor never arrives. Importing a file binds a single module map; a cycle hands back the partial map with a note instead of deadlocking, because a cell cannot wait forever for its own loop.

09

Splice variants

Mechanism · alternative splicing Most multi-cellular genes yield several mature mRNAs from one locus: the splicing machinery selects which exons survive, so one gene serves several tissues or stages without duplicating the locus. Operon's splice block declares the variants (each with its own parameter list); the call site stays identical and dispatch selects the active isoform. Selection order is deterministic, mirroring how a cell commits: the .cell methylation config wins, then the command line (--variant), then the first declared — the default isoform. operon build --variant bakes a single isoform into a standalone file, the way a terminally differentiated cell locks in its splicing program.

10

Fate machines

Mechanism · epigenetic landscape Cell identity behaves like a ball on a sculpted landscape: basins of attraction — fates — are separated by ridges, and transitions follow the valleys between neighboring basins. A cell does not teleport from stem to mature; it passes through committed intermediates, and some moves are simply uphill and impossible. fate encodes the landscape as declared transitions. .shift(s) returns true when the move follows a drawn valley; an illegal request returns false with a note and the state stays where it is — the valley semantics: rejection is not failure, it is geography. .can(s) reads the map without moving.

11

Regulate, toggle, repressilator

Mechanism · regulatory networks & synthetic circuits Promoters talk to promoters. A transcription factor activates its target with a measurable strength, and repressors subtract from it — a signed, weighted graph that cells propagate as signaling waves. regulate declares that graph; grn_fire("a") seeds a source and propagates wave by wave, with each hop damping the influence by its strength exponent — signal attenuation along a cascade, inhibition landing once per fire. The toggle is the classic mutual-repression latch: two repressors that cannot both win, so the system rests in exactly one of two stable states and toggle_on flips it — and a call to the repressed allele is refused softly, as null with a note. The repressilator is a ring of three repressors whose delayed mutual repression produces a self-sustaining oscillation; repressi_next() advances the ring deterministically (each step represses the previous gene, releasing the next), and with period the runtime runs it on a real clock as a living oscillator.

12

Frames & proofs

Mechanism · overlapping reading frames Compact genomes exploit every base: the same sequence read in a shifted frame yields a second, entirely functional protein, with the two products constrained never to corrupt each other. An Operon file is one sequence with two sanctioned readings. The expression frame is what operon run translates; frame proof { } overlays the test reading — the same file carries the program and its verification, physically adjacent so they evolve together. A proof that fails raises Stress burned and is recorded, but the suite keeps going — Total Grammar applies to testing too. operon test walks a tree of files, runs each file's proof frame, and reports files, proofs, passes, failures, and wobble-note counts in one sweep.
