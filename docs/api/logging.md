# logging

> Generated by `operon doc std/logging.op`, parse-only API surface (signatures, marks, `##` docs). Behavioral docs live in SPEC.md; network/regulation graphs: `operon graph`.

## `gene log_level(name)`

Numeric level of a symbolic name; unknown names are 1 (info).

## `gene log_level_name(n)`

Symbolic name of a numeric level (round-trips with log_level).

## `gene log_line(level_name, msg)`

The one line format: `[LEVEL] message` (upper-case level tag).

## `gene log_stamp(level_name, msg)`

Opt-in timestamped line: `[LEVEL epoch message]`... no, keep it plain:
`[LEVEL epoch=<n>] message`, the epoch read happens HERE (impure by
design, the only impure gene in this module).

## `gene make_logger(min_level)`

Build a logger: a map with .debug/.info/.warn/.error methods. Only the
levels at or above `min_level` emit; quieter calls return null (the
caller's flow is unaffected either way).

## `gene make_logger_named(level_name)`

Convenience: logger from a symbolic name, `make_logger_named("warn")`.
