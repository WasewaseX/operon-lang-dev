## `gene bin_hex_encode(data)`

Lowercase hex of a bytes value (or a string's UTF-8 bytes).

## `gene bin_hex_decode(s)`

Hex to bytes; a non-hex character or an odd length returns null
(a malformed decode is a caller bug, say so with a value, not a crash).

## `gene bin_u32le(v)`

## `gene bin_u32be(v)`

Unsigned 32-bit, big endian, to 4 bytes.

## `gene bin_i64le(v)`

Signed 64-bit, little endian, two's complement, to 8 bytes.

## `gene bin_read_u16le(data, at)`

Read u16 little/big endian at byte offset `at`; null on a short read.
The bound test is written overflow-free (len - at instead of at + n):
a huge `at` must answer null per the header contract, never raise the
language's i64 no-wrap overflow on the offset arithmetic itself.

## `gene bin_read_i64le(data, at)`

Read i64 little endian at byte offset `at`, sign-extended; null on a short
read. The accumulation keeps bit 63 out of the shifts (the language's
shift contract caps amounts at 63): seven bytes accumulate unsigned, the
eighth contributes its low 7 bits and its top bit decides the sign.
