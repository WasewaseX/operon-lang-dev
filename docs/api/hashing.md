# hashing

> Generated by `operon doc std/hashing.op`, parse-only API surface (signatures, marks, `##` docs). Behavioral docs live in SPEC.md; network/regulation graphs: `operon graph`.

## `gene hash_fnv1a32(data)`

FNV-1a 32-bit: the small fast workhorse for map keys and cache keys.

## `gene hash_djb2(data)`

DJB2 (x * 33 ^ c): classic string hash, 32-bit domain.

## `gene hash_sdbm(data)`

SDBM: another classic, better avalanche than DJB2 at the low end.

## `gene hash_adler32(data)`

Adler-32 (RFC 1950): two mod-65521 sums, cheap and order-sensitive.

## `gene hash_crc32(data)`

CRC-32 (IEEE 802.3, the zip/png polynomial), bitwise, no table.

## `gene sha256(data)`

SHA-256 (FIPS 180-4), pure integer arithmetic over 32-bit lanes.
Returns the 32-byte digest as a byte list; sha256_hex renders it.

## `gene sha256_hex(data)`

SHA-256 as the lowercase hex string (the usual interchange form).

## `gene hash_bytes_of(data)`

Byte view of the input: bytes stay as-is, strings encode as UTF-8,
anything else answers null (no byte view exists — the public hashes
answer null rather than silently hashing as empty).
