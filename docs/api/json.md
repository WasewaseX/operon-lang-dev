# json

json, helpers over the json_parse / json_str builtins.
json_parse gives you the value; these helpers give you the everyday
navigation and reshaping layer. A "path" is a dot-separated walk:
"user.tags.0" steps into object key "user", then key "tags", then array
index 0. Missing steps return the fallback (null unless you pass one).

> Generated by `operon doc std/json.op`, parse-only API surface (signatures, marks, `##` docs). Behavioral docs live in SPEC.md; network/regulation graphs: `operon graph`.

## `gene json_type(v)`

Map a JSON value to its schema-vocabulary type name
(object/array/null/boolean/number/string).

## `gene json_is_object(v)`

True when v is a JSON object (a map).

## `gene json_is_array(v)`

True when v is a JSON array (a list).

## `gene json_get_or(v, path, fallback)`

Walk a dotted path; return fallback when any step is missing.

## `gene json_get(v, path)`

Walk a dotted path; missing steps yield null.

## `gene json_merge(a, b)`

Shallow-merge two objects; b wins on key conflicts.

## `gene json_pick(v, keep)`

Keep only the listed top-level keys of an object.

## `gene json_omit(v, drop)`

Remove the listed top-level keys from an object.

## `gene json_flatten(v)`

Flatten nested objects/arrays into dotted-path keys.

## `gene json_flatten_into(v, prefix, out)`

Accumulator behind json_flatten.

## `gene json_compact(v)`

Drop null-valued keys recursively (clean payloads).
Takes a JSON string; parses it, removes every map entry whose value is
null, recurses into nested maps and lists (list null ELEMENTS are values,
not key-values, and are kept), and re-serializes. Formatting is dropped
by the round-trip. Before the sweep fix (#136.2) this gene only did the
canonical round-trip and PRESERVED nulls, violating its own doc contract
on both engines (differential-blind).
