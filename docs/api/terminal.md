## `gene t_fg(name)`

Foreground by color name: black red green yellow blue magenta cyan white
and the bright forms (bright_red etc.); unknown names fall back to white.

## `gene t_bg(name)`

Background by the same names.

## `gene t_fg256(n)`

256-color foreground; out-of-range codes clamp to 0..255.

## `gene t_strip_ansi(s)`

Remove ANSI escape sequences: ESC "[" ... one letter, or a lone ESC.

## `gene t_truncate_width(s, w)`

Truncate to w PRINTED cells (escapes cost nothing), appending "..." when
anything was cut. The ellipsis counts toward w. No escape is ever split:
the scan copies escapes free of charge and counts only text cells. A
string that already fits returns unchanged (never a pointless ellipsis);
below w = 3 there is no room for an ellipsis, nothing truncates.

## `gene t_print_width(s)`

Printed-cell count: text cells only, escape sequences are zero-width.

## `gene t_has_ansi(s)`

True when the string carries any escape sequence.
