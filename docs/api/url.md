# url

> Generated by `operon doc std/url.op`, parse-only API surface (signatures, marks, `##` docs). Behavioral docs live in SPEC.md; network/regulation graphs: `operon graph`.

## `gene url_encode(s)`

Percent-encode: every byte outside the unreserved set becomes %XX.

## `gene url_decode(s)`

Decode %XX (and "+" as space, the query form); a malformed escape keeps
its raw characters. Lenient by contract, never fails.

## `gene url_parse(u)`

Parse scheme://host[:port]/path?query into a map. Missing pieces are ""
and {}; the query part becomes a map of decoded key/value pairs. A
string with no "://" parses as a bare path (scheme "").

## `gene url_query_encode(m)`

Map to a canonical query string: keys sorted, both sides encoded,
"k=v" pairs joined with "&" (an empty map gives "").

## `gene url_is_unreserved(c)`

The RFC 3986 unreserved set, one character at a time.

## `gene url_hex_escape(cp)`

Uppercase two-digit hex for one code point (// keeps the digits integer;
a float into chr degrades to empty on both cores).

## `gene url_index_of(s, needle)`

Leftmost index of a needle (pure char scan; strings carry no index_of
on either core), -1 when absent.

## `gene url_rindex_of(s, needle)`

Rightmost index of a needle, -1 when absent.
