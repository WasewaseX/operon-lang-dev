1 · Lexical rules

  • Comments — # to end of line. A #! shebang is allowed on line 1. A # inside a string does not start a comment.
  • Strings — "double quoted" only. Escapes: \n \t \\ \" \{. Interpolation "{expr}" takes any expression, evaluated at runtime and str()-coerced.
  • Single quotes — no single-quoted strings in canonical form. A ' in code is a wobble: treated as " with a note.
  • Identifiers — [A-Za-z_][A-Za-z0-9_]*.
  • Numbers — 42 (int), 3.14 (float), 1e3 (float). Negative values come from unary minus.
  • Newlines terminate statements; ; is allowed and ignored (also ;;, stray). Blocks are { ... }.
  • Marks — @acetylate @methylate @m6a.
  • Extensions — .op source · .cell methylation config · .rna edit patches.

4 · Gene forms

Closures capture the defining environment by reference. Calls are positional with defaults; extra arguments are ignored with a note, missing arguments without a default arrive as null with a note — never a crash. The guard clause (uORF) sits between signature and body: if its condition is false, the else block runs; a non-null result from that block becomes the call result, otherwise the result is null plus a "guard tripped" note. Recursion is allowed; depth limit 10,000 → Stress overflow.

6 · The Total Grammar ladder

Every parse passes down the ladder; each rung below 1 emits notes — structured records of line, rung, message, repair. Nothing is ever rejected.

1

Canonical no notes

Exact keyword and grammar match. The file parses as written.

let x = 2 promote("answer {x * 7}") # → answer 42
2

Synonym known alternate spelling

A synonym table maps alternate spellings to canonical keywords: fn func def fun sub lambda proc → gene · print echo say show → promote · var val const → let · elseif → elif · foreach each → for · import include require → use · ret → return · stop → break · continue next skip → continue · yes on → true · no off → false · null nil none nothing → null · && → and · || → or · ! → not.

var x = 2 → rung-2 note, parsed as let x = 2 print("hi") → rung-2 note, parsed as promote("hi")
3

Wobble edit-distance repair

An identifier within edit distance ≤ 2 of exactly one keyword (≤ 1 if its length ≤ 4) is repaired to that keyword, with a note. Applies to marks too. Ambiguity — two keywords equidistant — falls to rung 4 for that token.

les x = 2 → note: repaired les → let (distance 1) — runs normally @acetylat gene f() {} → note: mark repaired → @acetylate
4

Semantic fallback degrade, never reject

An unknown bare identifier in expression position becomes the string literal of its own name, with a note ("unbound wobble"). Stray tokens are skipped with notes. Unclosed braces are auto-closed at EOF with notes. Extra closers are skipped with notes. An unclosed string consumes to EOF with a note.

promote(greeting) → note: unbound wobble — "greeting" used as string literal } → note: skipped extra `}` — run continues

Runtime Total Grammar. Reading an unbound variable → null + note; calling a non-gene → null + note. A run never aborts on soft failures — only exit() or an uncaught raise-style hard event ends it early (and even that prints a containment note first). Undefined gene calls are reported by operon check as phantom calls.

8 · Methods

9 · CLI reference

  • operon test defaults to tests/ recursively; each file's proof frames run, failures are recorded, the suite continues; exit 1 on any failure. Report: files, proofs run, passed, failed, wobble notes.
  • --strict → exit code 3 if any rung ≥ 3 note occurred.
  • Stdout discipline — promote prints program output; notes/reports go to stderr, so operon run f.op > out.txt is clean. --json on check/test/profile/crispr emits machine-readable JSON to stdout.

10 · Grading model

operon check grades a file the way the cell grades a transcript — by accumulated damage, not by rejection:

EventPenalty
Start100
Wobble note (rung 3)−2
Fallback note (rung 4)−3
NMD premature stop (unreachable after return)−4
Untranslated transcript (defined, never called, unexported, unenhanced)−1
Phantom call (calling an undefined gene — runs as null)−2
Floor50

Letters: A ≥ 90 B ≥ 80 C ≥ 70 D ≥ 60 F else. The playground applies the same arithmetic live — wobble −2, fallback −3, floor 50 — as its score chip.
