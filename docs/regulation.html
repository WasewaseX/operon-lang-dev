The regulation layer

A genome is not just a program — it is a program under regulation. The same DNA yields different cells because expression is layered: architectural folding, chromatin marks, transcript surveillance, controlled entry, containment programs, and telemetry. Operon implements that layer as executable language semantics. Every feature below is real, implemented, and tested — none are decorative.

1 · Insulation: TADs and anchors

The interphase genome is partitioned into topologically associating domains (TADs) — regions whose loci contact each other far more frequently than they contact neighbors, bounded by architectural protein binding sites (classically CTCF anchor sites, often reinforced by cohesin extrusion). The functional consequence is enhancer insulation: a regulatory element inside the loop drives promoters inside the same loop and is blind to promoters across the boundary. Breaking a boundary — in development or disease — lets an enhancer hijack a foreign promoter, and the result is misexpression.

Operon encodes this as visibility semantics. A tad Name { } block is an insulation domain: names declared inside are lexically captive. They escape only through an anchor export statement placed inside the same tad — the anchor site on the loop. A file with no anchor export anywhere is default-open (all top-level genes and lets exported), mirroring a loop-less, unstructured region. anchor import x; is the declarative counterpart: it asserts that this domain expects an external factor to exist, which operon check verifies (a missing factor is a note, not an error). Tads do not nest — attempted nesting degrades to a merged domain with a note, because real loops cannot meaningfully contain a second independent loop boundary at the same scale. use imports bind one module map per file, with a module cache so the same transcript is not re-executed, and cyclic imports return the partial map with a note rather than deadlocking.

2 · Enhancers and chromatin marks

Super-enhancers are dense clusters of enhancer elements bound by unusually high concentrations of transcriptional machinery; they preferentially drive the genes that define a cell's identity, and their perturbation disproportionately reshapes the expression profile. In Operon, enhance a, b, c; marks a cluster of genes as priority targets: operon profile shows the enhancement flag per gene, and operon check awards a codon-score bonus to enhanced hot genes — investing grading weight where expression investment actually lands.

Histone marks are the second layer. Acetylation of histone tails neutralizes their positive charge, loosens DNA wrapping, and generally means eager, transcribable chromatin; repressive methylation compacts nucleosomes and locks regions down. The marks are epigenetic: the DNA sequence is untouched, but the behavior of the region changes. Operon's @acetylate marks a gene as eager/priority — it is excluded from silence rewriting (and from toggle-gated call refusal), because active chromatin stays active. @methylate represses a gene: calls to it still run (repression is not deletion), but the first call emits a soft "methylated call" note — the cell does not narrate every repression, so later calls are silent — and the note disappears entirely when the .cell config sets methylate.quiet = true. Neither mark edits the function body: the layer sits above the source, exactly as epigenetics sits above the genome.

3 · Transcript surveillance: NMD, RISC, editing

Cells audit their transcripts three ways, and Operon implements all three as distinct tools.

Nonsense-mediated decay (NMD) degrades mRNAs carrying a premature stop codon — typically one upstream of an exon-junction complex, the molecular signature of a splicing mistake. The cell would rather destroy a truncated product than let it accumulate. operon check --nmd is that sweep over source code: premature stops are statements unreachable after an unconditional return (dead transcript downstream of a stop signal, −4 each in grading), and untranslated transcripts are genes that are defined but never called, not exported, and not enhanced (−1, informational). --nmd purge rewrites the file without them — decay, executed.

miRNA/RISC silencing is post-transcriptional and sequence-directed: a small RNA guides the RISC complex by base-pairing to a complementary target, and the complex then redirects or degrades that specific transcript — regulation without touching the gene itself. The Operon statement silence old -> new; does precisely this at the call level: after the statement executes, every call to gene old is transparently redirected to new with a "RISC: call silenced" note. @acetylate genes are immune, as active chromatin is. Crucially, same-name splice variants resolve first, and silencing applies to the resolved name — guide specificity is judged after isoform identity, which is how real targeting works.

RNA editing chemically amends individual transcript bases after transcription, changing what the message says without changing the gene. Operon's .rna files are patch lists: edit target { replace "src" -> "dst"; } where target is a file or gene name; the patch is applied to the target's source text before parsing, each applied replacement logged as a note. This makes them hot-fixes with a full audit trail — invoked with operon run app.op --rna hot.rna, never silently.

4 · Entry: m6A priority and IRES

m6A (N6-methyladenosine) is the most abundant internal mRNA modification; among its many roles is steering which reading of a message wins — reader proteins bound at m6A sites influence processing, export, and translation efficiency. Operon distills this to a resolution rule: among same-name candidates — splice variants, shadowing definitions — the @m6a-marked one wins dispatch. One mark, one priority, deterministic.

IRES elements (internal ribosome entry sites) allow translation initiation in the middle of a message, cap-independently — the ribosome lands where the element says, not at the 5′ cap. Operon's ires name; declares a cap-independent entry gene, and operon run --ires (or running a file with no main) begins execution at the first declared IRES target instead of the canonical entry. A program therefore has a defined default reading and an alternative internal one, both first-class.

Codon optimality — the observation that synonymous codons are translated with different efficiencies — appears as codon(s), a deterministic 0–100 style score of an identifier read by operon check style notes: concise, digit-free, well-shaped names read better higher, and the score feeds the same letter-grade report as wobble penalties.

5 · Proteostasis: UPR/ISR stress programs

The unfolded protein response and the broader integrated stress response are graded containment programs, not panics: sensors detect accumulated damage, translation narrows, specific rescue genes are induced, and if adaptation fails only then does the cell commit to apoptosis. The key property is specificity with containment — the response is proportionate to the lesion class.

Operon's stress { } rescue { } implements exactly that contract. Runtime failures raise a Stress value — a map {"kind": Str, "message": Str} — with kinds named for lesion classes: unfolded (type errors, e.g. ordering incompatible values), missing (bad index/key/member/null dereference), overflow (integer overflow, recursion depth), burned (assertion failures, resource errors). An unqualified rescue catches any kind; stress missing { … } filters to that kind only and lets others propagate outward — lesion specificity. The rescue binding is optional (rescue (e)), and with no rescue clause the stress is contained to null plus a note. Nothing here is an exception in the crash sense: Total Grammar holds at runtime, and a stressed region degrades, logs, and lets the run continue.

6 · Cell identity: fate landscapes and circuits

Fate landscapes. Development is often pictured as a ball rolling over a landscape whose valleys are cell fates and whose ridges separate basins of attraction: transitions follow connected valleys, some moves are uphill-impossible, and a blocked move leaves the cell where it was. fate Name { state a -> b, c; … enter a; } declares that map; Name() instantiates at the enter state. .shift(s) returns true when a declared transition exists — and false with a note and an unchanged state otherwise: the valley stay. .can(s) surveys without moving. Instances are ordinary maps with hidden #fate/#state keys, so fate is inspectable but not casually overwritable.

Gene regulatory networks. Promoters regulate promoters: activators raise target expression with measurable strength, repressors subtract from it. regulate { a activates b strength 0.8; c inhibits d; } declares the signed, weighted graph (default strength 1.0). The network is stateful: levels persist across grn_fire("a") calls — levels that persist across fires by default (decay is opt-in dilution) — and each fire seeds the source additively, capped at 1.0. Each fire runs in two phases. Phase 1, activation: influence propagates in waves, child = max(child, parent × strength^wave) — each hop attenuates by another factor of strength, as in a signaling cascade. Phase 2, inhibition: each repressor applies its influence exactly once per fire, child = max(0, child − parent × strength), based on the source's post-activation level — a repressor's concentration sets the output level; it does not compound across waves. An edge may carry an optional threshold t (dose–response, n = 2): influence = strength × p² / (p² + t²) where p is the parent level — weak below the threshold, saturating above it, the sigmoid dose–response of a real binding site. grn_state() returns the level map of every gene in the graph.

The toggle switch. Two repressors arranged so that each shuts the other off form a mutual-repression latch: the system rests in exactly one of two states, and it remembers which until actively flipped. toggle a, b; declares the pair; toggle_on("a") turns a on and b off; toggle_state() reports both. The invariant is absolute — exactly one may be on — and the pair gates calls: invoking the repressed allele returns null with a note (toggle repressed: 'x' is the inactive allele ('y' is on)). @acetylate genes are immune; open chromatin wins.

The repressilator. A ring of three repressors, each repressing the next, produces self-sustaining oscillation — the synthetic-biology demonstration that a regulatory topology alone can generate a clock. repressilator a -> b -> c; declares the ring. repressi_next() advances it one tick (the ring integrates a reduced, protein-only variant of the Elowitz–Leibler model — α=10, γ=1, Hill h=4, 20 Euler substeps per tick — so the ~6-tick oscillation and the one-tick repression lag are emergent, not scheduled; repressi_state() returns the continuous level of every node) — the reproducible mode tests rely on. Declaring it with period 3 immediately spawns a real OS thread flipping the ring every 3 seconds, and repressi_start(ms) restarts the timed ring with an explicit millisecond period — the demo mode, an actual oscillator against the wall clock.

7 · Telemetry: the single-cell layer

Single-cell transcriptomics reads expression per cell rather than per bulk culture, and the quantity that separates a bursty gene from a steady one is transcriptional burst kinetics: counts sampled over fixed windows give a variance-over-mean ratio — the burst index — that is high for genes fired in occasional bursts and near zero for constitutively expressed ones. And the fraction of a gene population that has actually been read out — genes called at least once, over all genes defined — is the transcript maturation share: the honest, measurable counterpart of the velocity idea, without pretending to infer direction from a single cell.

fingerprint() returns exactly this for a run. The run's global call clock is sliced into complete bins of 20 gene calls (a trailing partial bin is dropped); each gene's count per bin is one sample, and its burst index is the variance of those samples over their mean — 0 for a gene with one or fewer calls or a single bin. The returned map carries calls (gene → count), mature (genes called at least once), nascent (defined but never called), maturation (mature / total — the transcript maturation share), burst (the mean per-gene burst index), and burst_by_gene. operon profile f.op runs instrumented and prints the per-gene table — calls, exclusive self-time in microseconds (children subtracted, so a wrapper gene shows only its own overhead), flags (enhanced active repressed) — followed by the mature · nascent · maturation summary and enhance candidates: the hot genes (called at least 10% as often as the most-called gene) that carry no enhance annotation yet. Telemetry is not a bolt-on debugger; it is the same readout a profilometer gives a culture.

8 · Perturbation: knockout screens

A CRISPR knockout screen disables one gene at a time across a population and records which knockouts change the phenotype — causal maps built by systematic ablation. Operon's operon crispr f.op --knockout gene is that protocol for code: the target gene's body is rewritten to return null, the file's proof frames are then run, and survivors (proofs that still pass) are reported — with --json for machine consumption. operon crispr f.op --matrix runs the whole screen: every top-level gene is knocked out in turn and the viability table printed (a gene whose knockout breaks a proof is marked ESSENTIAL; one whose knockout changes nothing is dispensable — probably dead code, arguably a nascent transcript). The epigenetic counterpart completes the layer: the .cell methylation config (key = value lines, section headers, # comments; auto-detected as operon.cell) carries keys the implementation consumes — variant.<splice>, methylate.quiet, wobble.strict, entry — and programs read their own configuration via methyl("key", default?), the way a locus reads its own methylation state.

One law above the layer. Regulation never rejects: silencing redirects, methylation notes, NMD purges, knockouts null out. Every mechanism here modifies behavior with a record rather than failing the run — the Total Grammar law, extended from parsing to expression.
